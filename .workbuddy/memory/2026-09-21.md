### 本次踩到并记进 AGENTS.md §11.6 的真坑

**Radix Portal 首次提交渲染 `null`**（容器靠自身 `useLayoutEffect` 挂上），所以 `DialogContent` 里
`useRef + useEffect([])` 读到的 `current` 一定是 `null`，之后 ref 挂上 effect 也不会重跑 →
导出弹窗预览区永远是 0 宽、`scale(0)` + `visibility: hidden`，一片空白。
**修法**：回调 ref + state（`const [box, setBox] = useState(null)`，`ref={setBox}`，effect 依赖 `[box]`）。
定位靠「effect 里打一行 log + CDP 收 `Runtime.consoleAPICalled`」，比盯截图猜快得多。
